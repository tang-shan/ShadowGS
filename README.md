
# Shadow-Aware 3D Gaussian Splatting via Lambertian-Guided Neural Masking

> **Update (June 2026)**

![Teaser](https://github.com/tang-shan/ShadowGS/blob/master/static/images/teaser.png)

When images are captured in unconstrained environments using handheld devices,
transient shadows caused by photographers or surrounding objects are often included in the training views.
Vanilla 3D Gaussian Splatting tends to encode these shadows into appearance or geometry,
leading to view-dependent artifacts in novel view synthesis.

---

![Method](https://github.com/tang-shan/ShadowGS/blob/master/static/images/framework.png)

We propose a shadow-aware 3D Gaussian Splatting framework that generates a candidate shadow prior from shadow-minimal training views and refines it using a residual-driven neural classifier. A Lambertian constraint is applied to suppress view-dependent compensation within shadow regions. The final shadow mask is used as a pixel-wise reliability weight for photometric supervision.

## Data Preparation

For shadow-distractor scenes, we construct candidate shadow masks using a clean-reference reconstruction pipeline. Specifically, a subset of training images with minimal shadow contamination is selected from the training split only (no test views are used). A standard 3D Gaussian Splatting (3DGS) model is trained on this subset to obtain a clean reference reconstruction.

Candidate shadow masks are then generated by computing photometric residuals between rendered images (via render_coarse.py) and observed images. The resulting masks are stored in shadow_masks/ and used during optimization.

For object-distractor scenes, segmentation masks are generated using Segment Anything (SAM)~\cite{kirillov2023segment}. We use the official ViT-B checkpoint.
